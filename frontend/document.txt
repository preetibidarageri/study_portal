-------------------------------------STEP 1 : Set up the project-------------------------
1.  python3 --version

2.  mkdir SKSV-study-material-website

3.  cd backend

    Activate it: source venv/bin/activate

4.  Install Django and the required packages
    python -m pip install --upgrade pip
    pip install django djangorestframework django-cors-headers djangorestframework-simplejwt "psycopg[binary]" Pillow

packages
1. Django: Backend framework
2. Django REST Framework: APIs for React
3. django-cors-headers: Allows the React frontend to communicate with Django
4. Simple JWT: Token-based authentication,	Handle login authentication using tokens
5. psycopg: PostgreSQL database connection
6. Pillow: Image processing support for Django

5.  Verify Django installation
    django-admin --version

-------------------------------------STEP 2 : Create the Django project-------------------------

1. Check that you are in the backend folder : engineering-study-portal/backend
2. Create the Django project : django-admin startproject config .
3. Run the initial database migrations : python manage.py migrate(creates database tables using SQLite)
4. Start the Django server : python manage.py runserver

------------------------------------Step 3: Install PostgreSQL and connect it to Django.-----------------------

1: Install PostgreSQL : sudo apt update
                        sudo apt install postgresql postgresql-contrib -y
    Check whether PostgreSQL is running: sudo systemctl status postgresql
    psql --version

2: Create the PostgreSQL database: sudo -u postgres psql
    create a database user: CREATE USER study_user WITH PASSWORD 'StudyPortal_2026_Strong';
    Create your project database: CREATE DATABASE study_portal OWNER study_user;
    Give the user permission to connect: GRANT CONNECT ON DATABASE study_portal TO study_user;
    Exit PostgreSQL: \q

3:  Connect Django to PostgreSQL
    cd ~/engineering-study-portal/backend
    source venv/bin/activate
    Confirm that the PostgreSQL driver is installed: pip install "psycopg[binary]"
    Now open the Django settings file:
    Find the section beginning with:

import os

DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.postgresql",
        "NAME": os.environ.get("DB_NAME", "study_portal"),
        "USER": os.environ.get("DB_USER", "study_user"),
        "PASSWORD": os.environ["DB_PASSWORD"],
        "HOST": os.environ.get("DB_HOST", "localhost"),
        "PORT": os.environ.get("DB_PORT", "5432"),
    }
}

4:  Set the database credentials: 
    export DB_NAME=study_portal
    export DB_USER=study_user
    export DB_PASSWORD='StudyPortal_2026_Strong'
    export DB_HOST=localhost
    export DB_PORT=5432

5: Test the database connection: python manage.py check
    python manage.py migrate
    python manage.py runserver

---------------------------------Step 4: Create a Django superuser-------------------

1. Create the superuser: python manage.py createsuperuser

(NOTE: pip install psycopg2-binary :- Django is written in Python, and PostgreSQL is written in C. 
Python cannot natively send queries (like SELECT * FROM users) to a PostgreSQL database. 
psycopg2 is the official database driver (the translator) that connects Django to PostgreSQL.)

----------------------------------Step 14: Create the registration serializer(create the student and teacher registration API.)--------------------------

    A serializer converts data received from React into Django database records. 
    It will also validate the registration details and securely hash passwords.

1 — Create serializers.py : inside study portal app

    write serializer code to  
        Accepts username, name, email, and password.
        Allows only student or teacher roles.
        Checks whether the email is already registered.
        Requires a password of at least 8 characters.
        Hashes the password instead of storing it as plain text.
        Automatically creates the corresponding student or teacher profile.
